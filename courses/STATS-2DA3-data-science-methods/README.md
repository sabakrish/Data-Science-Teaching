# Data Science Methods — teaching map
Independent planning document; verify the current official course outline before claiming exact syllabus alignment.

## Proposed learning outcomes
1. Formulate answerable questions from data.
2. Inspect, clean, summarize, and visualize tabular data.
3. Explain sampling, variability, and association.
4. Build and interpret a baseline regression model.
5. Communicate findings with caveats.
6. Produce reproducible analyses.

## Proposed sequence
Data questions and provenance; Python/pandas; missing data and data quality; descriptive statistics; visualization; sampling and association; linear regression; train/test evaluation; reproducible reporting.

## Assessment ideas
Notebook exercises, interpretation quiz, exploratory analysis, and a final mini-project.
