# Data Science Teaching Portfolio
**Independent undergraduate teaching portfolio | Dr. Krish Sabapathy**

This repository presents independently developed teaching resources and reproducible examples in data science, statistics, machine learning, and scientific computing.

> This is not an official McMaster University repository and is not affiliated with or endorsed by McMaster University. Course folders are planning maps, not official syllabi.

## Repository map
- `courses/`: learning outcomes, proposed topic sequences, assessment ideas
- `projects/`: undergraduate project examples
- `assignments/`: student-facing briefs
- `assessment/rubrics/`: marking criteria
- `resources/`: setup and reproducibility guidance

## Featured project
**Student Performance Analysis** uses a synthetic dataset to demonstrate data inspection, exploratory analysis, visualization, correlation, and cautious interpretation. It does not represent real students.

## Setup
Install Python 3.10+, then run:
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter lab
```
Open `projects/01-student-performance-analysis/notebooks/student_performance_analysis.ipynb`.
