# Undergraduate Data Science Teaching Portfolio
**Independent teaching portfolio | Dr. Krish Sabapathy**

This repository contains original undergraduate-level course plans, learning materials, reproducible Python notebooks, projects, assignments, and assessment rubrics in data science, statistics, machine learning, and scientific computing.

The portfolio is **university-neutral**. It is not an official repository for any university and is not affiliated with or endorsed by any institution. Course plans are synthesized from published Canadian undergraduate curriculum descriptions and supplemented with appropriate undergraduate topics. They are not copied from, or presented as official versions of, any university's syllabus.

## Curriculum design principles
- Start with a coherent progression from data handling to statistical reasoning and modelling.
- Include theory, implementation, diagnostics, interpretation, and communication.
- Cover introductory and advanced methods, with clear prerequisites and scaffolding.
- Use Python as the primary executable environment, while noting where R can be used as an alternative.
- Include reproducibility, ethics, privacy, fairness, and limitations.
- Make every completed project include student tasks and assessment criteria.

## Repository structure
- `syllabi/` — generic course syllabi and topic maps
- `curriculum/` — topic coverage matrix and curriculum reference notes
- `courses/` — course-specific learning outcomes and teaching plans
- `projects/` — end-to-end undergraduate project examples
- `assignments/` — student-facing briefs
- `assessment/rubrics/` — assessment criteria
- `resources/` — environment setup and reproducibility checklist

## Courses represented
1. **Foundations of Data Science Methods** — programming for data, data wrangling, visualization, exploratory analysis, predictive modelling, k-nearest neighbours, k-means, resampling, and reproducible reports.
2. **Applied Data Science Methods** — regression and classification, decision trees, random forests, bagging, boosting, Ridge/LASSO, generalized additive models, PCA/SVD, multiple testing, sensitivity/specificity, cross-validation, and bootstrap.
3. **Data Science Theory and Statistical Learning** — statistical reasoning, sampling and uncertainty, estimation, model assumptions, generalization, bias–variance, validation, algorithmic foundations, ethics, and responsible communication.
4. **Supporting methods** — time series, scientific computing, numerical methods, optimization, and mathematical modelling.

## Getting started
Install Python 3.10 or later and install packages listed in `requirements.txt`. See `resources/SETUP.md`. Start with the notebook in `projects/01-student-performance-analysis/notebooks/`.

## Status and integrity
The student-performance dataset is synthetic and intended only for practice. Several project folders are specifications for future work and are explicitly labelled as planned. Do not describe a planned project as completed until its notebook is implemented, tested, and reviewed.
