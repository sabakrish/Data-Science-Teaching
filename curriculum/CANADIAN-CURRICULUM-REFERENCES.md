# Canadian Curriculum References

This portfolio uses public curriculum descriptions as **topic-level references**. These sources guide coverage, but the syllabi and teaching materials in this repository are independently written and should not be represented as official course documents from these universities.

## 1. McMaster University — Statistics course listings
Published description of STATS 2DA3 includes the R ecosystem, data handling, programming, model building, visualization, predictive modelling, bootstrap/cross-validation, k-nearest-neighbour regression and k-means. The published description of STATS 3DA3 lists classification, clustering, decision trees, random forests, bagging, boosting, Ridge/LASSO, generalized additive models, PCA/SVD, multiple hypothesis testing, sensitivity/specificity, cross-validation, bootstrap and scientific communication.

- Official calendar PDF: https://registrar.mcmaster.ca/wp-content/uploads/2025/06/ug-calendar-covers-web.pdf

## 2. University of Toronto — Statistical Models for Data Science (STA272H1)
The official calendar description includes question formulation, data collection and cleaning, visualization, statistical inference, predictive modelling, regression, classification, neural networks, clustering, measurement error and prediction.

- Official academic calendar: https://artsci.calendar.utoronto.ca/course/sta272h1

## 3. University of Toronto — Data Science I (JSC270H1)
The official calendar describes data exploration and preparation, visualization and presentation, computing with data, professional communication, ethics, and integrated workflows/case studies.

- Official academic calendar: https://artsci.calendar.utoronto.ca/course/jsc270h1

## 4. University of British Columbia — DATA 311: Machine Learning
The published syllabus describes regression, classification, resampling, model selection and validation, matrix properties, dimension reduction, tree methods and unsupervised learning. It also lists cross-validation, Ridge/LASSO, bagging/boosting, PCA and k-means.

- Course syllabus: https://irene.vrbik.ok.ubc.ca/quarto/machine-learning/syllabus.html

## 5. University of Waterloo — Data Science degree
The program page identifies supporting areas including statistics, computer science, applied mathematics and combinatorics/optimization, and examples of upper-year courses such as Computational Statistics and Data Analysis, Optimization Models and Algorithms for Data Science, Scientific Machine Learning and a Data Science capstone.

- Official program page: https://uwaterloo.ca/future-students/programs/data-science

## How these sources are used
- Topics explicitly listed in published descriptions inform the core coverage matrix.
- Topics added to create a complete undergraduate learning progression are marked as proposed extensions.
- Course names and codes are used only to identify reference sources, not to imply that this repository is institutionally approved or course-equivalent.
- Official course outlines may change; check the current institutional calendar before using this mapping for formal curriculum approval.
