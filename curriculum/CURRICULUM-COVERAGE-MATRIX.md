# Undergraduate Data Science Curriculum Coverage Matrix

This matrix is a design and audit tool for the portfolio. It synthesizes public descriptions of Canadian undergraduate courses and then adds related topics to make a coherent teaching sequence. It is not an official equivalency or claim that any institution teaches every listed topic in one course.

| Topic | Foundations | Applied methods | Theory/statistical learning | Portfolio evidence |
|---|---|---|---|---|
| Data workflow and question formulation | Core | Review | Core | Project briefs |
| Data import, cleaning, wrangling | Core | Core | Applied | EDA notebook |
| Programming for data and reproducibility | Core | Core | Core | Jupyter notebooks, setup guide |
| Visualization and communication | Core | Core | Core | EDA project, report rubric |
| Descriptive statistics and EDA | Core | Review | Core | Student-performance project |
| Sampling, uncertainty and inference | Introductory | Multiple testing/resampling | Core | Theory syllabus |
| Regression | Introductory | Multiple regression, diagnostics, Ridge/LASSO, GAM | Mathematical foundations | Housing regression project (planned) |
| Classification | Introductory | Logistic regression, trees, ensembles | Theory and validation | Classification project (planned) |
| K-nearest neighbours | Introductory | Comparison method | Algorithmic foundations | Foundations labs |
| Clustering | K-means introduction | Clustering comparison | Distance, assumptions | Clustering extension |
| Decision trees | Introductory concept | Core | Algorithmic properties | Classification project (planned) |
| Bagging/random forest/boosting | Overview | Core | Generalization and ensembles | Classification project (planned) |
| Cross-validation | Introductory | Core | Theory and limits | Resampling lab |
| Bootstrap | Introductory | Core | Uncertainty | Resampling lab |
| PCA/SVD and dimension reduction | Preview | Core | Matrix foundations | PCA notebook (planned) |
| Sensitivity/specificity and other metrics | Introductory | Core | Decision rules | Classification project |
| Multiple hypothesis testing | Preview | Core | Inference and error rates | Theory notes (planned) |
| Time-series analysis | Extension | Supporting module | Optional | Forecasting project (planned) |
| Scientific computing/optimization | Supporting module | Extension | Mathematical foundations | Optimization project (planned) |
| Ethics, privacy, bias and limitations | Core | Core | Core | Every project and rubric |
| Scientific communication | Core | Core | Core | Report and presentation rubrics |

## Coverage rules
- “Core” means explicitly taught and assessed in the proposed syllabus.
- “Introductory” or “Preview” means a first exposure, not full mastery.
- “Planned” evidence must not be presented as a completed project until the notebook exists and has been tested.
