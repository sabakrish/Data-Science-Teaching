# Generic Undergraduate Syllabus: Foundations of Data Science Methods

**Level:** Undergraduate, introductory/intermediate  
**Indicative duration:** 12 teaching weeks  
**Programming environment:** Python/Jupyter; selected R alternatives may be provided  
**Prerequisite assumptions:** Introductory programming, algebra, and introductory statistics or equivalent preparation

## Course description
Students learn a reproducible workflow for turning data into defensible evidence. They work with tabular data, programming, visualization, exploratory analysis, introductory prediction, regression, clustering, and resampling. Emphasis is placed on interpreting results, explaining uncertainty, and communicating findings rather than simply producing code.

## Learning outcomes
By the end of the course, students should be able to:
1. Formulate a question that can be investigated using data.
2. Import, inspect, clean, transform, and document data.
3. Create effective static and interactive visualizations.
4. Summarize distributions, associations, and uncertainty.
5. Explain the purpose and limits of predictive modelling.
6. Implement and assess basic regression, k-nearest-neighbour, and k-means methods.
7. Use train/test separation and introductory cross-validation or bootstrap resampling.
8. Produce a reproducible report and communicate conclusions with appropriate caveats.
9. Identify privacy, bias, ethical, and data-quality concerns.

## Indicative weekly schedule
| Week | Topics | Practical evidence |
|---|---|---|
| 1 | Data science workflow; questions, variables, data provenance | Question and data audit |
| 2 | Python/Jupyter, data structures, tabular data, reproducible scripts | Notebook fundamentals |
| 3 | Data import, types, missingness, cleaning and transformation | Data-cleaning lab |
| 4 | Descriptive statistics, distributions, sampling and variability | Summary and interpretation |
| 5 | Visualization principles, chart selection, misleading displays | Visualization critique |
| 6 | Exploratory data analysis, correlation and association | EDA mini-report |
| 7 | Predictive modelling workflow, baseline models, train/test split | Baseline model |
| 8 | Regression foundations and k-nearest-neighbour regression | Regression comparison |
| 9 | Classification concepts and introductory metrics | Classification exercise |
| 10 | Clustering with k-means, scaling, distance and interpretation | Clustering lab |
| 11 | Bootstrap, cross-validation, uncertainty and model assessment | Resampling lab |
| 12 | Reproducible reporting, ethics, communication and project presentation | Final project |

## Assessment blueprint (adaptable)
- Weekly practical notebooks: 20%
- Data visualization and EDA assignment: 20%
- Predictive-modelling assignment: 20%
- Final reproducible project and report: 30%
- Participation, peer review, or short reflection: 10%

Assessment weights are illustrative and should be adjusted to the institution's policies and the course level.

## Core software skills
Python, Jupyter, pandas, NumPy, Matplotlib/seaborn, scikit-learn, version control, and reproducible reporting. Equivalent R-based activities can use tidyverse, ggplot2, and appropriate modelling packages.

## Teaching approach
Use short conceptual lectures, worked examples, guided labs, student interpretation questions, and scaffolded projects. Provide starter notebooks first, then gradually remove scaffolding as students gain independence.
