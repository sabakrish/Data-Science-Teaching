# Project 1 — Student Performance Analysis
**Level:** Introductory undergraduate | **Tools:** Python, pandas, Matplotlib, seaborn  
**Data:** Synthetic teaching data generated for this portfolio.

## Question
How are study time, attendance, and prior assessment results associated with final scores in a simulated dataset? This is not a causal study and does not describe real students.

## Learning outcomes
Inspect a CSV; check missing values and ranges; visualize distributions and relationships; calculate correlations; communicate limitations.

## Files
- `data/student_performance_synthetic.csv`
- `notebooks/student_performance_analysis.ipynb`

## Student extensions
1. Compare final scores by study-time category.
2. Examine attendance and study time together.
3. Fit a simple exploratory regression and discuss limitations.
4. Identify two missing variables that could matter.
